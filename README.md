# LYNX CHAT v2 🐆

Talk to strangers — **video + voice + text**, with country matching and flags.

## What's new in v2
- ✅ Working two-way **camera + microphone** (WebRTC, Google STUN servers)
- 🎤 📷 One-tap **mic / camera toggle** buttons (no reconnect needed)
- 🌍 **Country selection** with emoji flags (130+ countries)
- 🇸🇦 Match preference: **Worldwide** or **Same country only**
- 💬 Built-in **text chat** panel (works even if camera/mic is blocked)
- ⏭️ **Next / Skip** button, live online counter, typing indicator

## Deploy to Render (free)
1. Upload all files in this folder to your GitHub repo **root** (including the `public/` folder).
2. Render → New Web Service → connect the repo.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Root Directory: *(leave blank)* → Create.

## Run locally
```
npm install
npm start
```
Then open http://localhost:3000 in two tabs to test.

> Camera & mic only work on **HTTPS** (Render provides this) or `localhost`.
